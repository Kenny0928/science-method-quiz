# 科展研究方法測驗

給國中科展培訓學生使用的 25 題單選測驗，範圍限於已教過的文獻解構、相關與因果、圖表選擇與判讀。網頁可直接由 GitHub Pages 提供，不需要安裝套件或建置。

## 學生流程

1. 填寫姓名，逐題作答。
2. 檢查 25 題是否完成，再按「送出並計分」。
3. 成績接收程式在 Google Sheet 核對答案、計分及儲存每題選項。
4. 網頁確認記錄成功後顯示分數和逐題解析。送出失敗時保留本頁答案，可重試；同一送出編號不會重複寫入。

## 成績表與計分

成績表有兩個工作表：

- `作答紀錄`：送出時間、編號、姓名、得分、總題數、百分比與 Q01–Q25 的作答選項。
- `題目對照`：題目、四個選項、正確答案與解析。網站不包含答案；計分程式從這張表讀取答案。

Google Apps Script 必須由成績表的「擴充功能 → Apps Script」建立成**綁定專案**，並部署成 Web App，執行身分設為表格擁有者。部署後把 `/exec` 網址填入 `config.js`。學生無須登入 Google 帳號；網址公開後，任何取得網址的人都可送出，因此請勿把成績表設定為公開共用。若要限制僅指定學生提交，需要另外加入身分驗證。

## 題庫依據

依上層目錄 `玩遊戲複習研究方法/00_出題指引_知識架構.md` 編題：A／B／C 題數為 10／10／5，遷移題 16 題；未納入統計進階與 Google 工具操作。圖表內數字是教學用虛擬資料。

## 更新題目

修改 `questions.js` 的題目或選項時，必須同步修改成績表 `題目對照` 的同題資料與正確答案，並在網站和 Apps Script 一起更新測驗版本。正式施測中不宜修改題目或答案。

## 本機預覽

在此資料夾執行 `python3 -m http.server 8766`，開啟 `http://127.0.0.1:8766/`。正式網站由 GitHub Pages 指向儲存庫根目錄。
